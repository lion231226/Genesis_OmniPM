## 二、已知限制

| # | 限制 | 影响 | 计划 |
|---|------|------|------|
| 1 | 6 对低频混合型交织矩阵仅为骨架定义 | 非高频混合型项目需 Agent 手动协调 | v1.0.0 升级为完整矩阵 |
| 2 | CDL 仅搜索 PI + GitHub 生态 | 不支持 GitLab/Bitbucket 等私有源 | 通过 `.pi/` 的 `custom_sources` 字段扩展 |
| 3 | 状态机在单一会话中运行 | 跨会话恢复依赖 PROJECT_MEMORY.md 的手动检测 | v1.0.0 实现自动化恢复 |
| 4 | Token 预算为 Agent 估算值 | 非 API 精确计数，跨模型误差不补偿 | 标注为估算值，用户自行校准 |
| 5 | 无自动化回归测试套件 | 提示词变更后需手动验证 31 个测试用例 | v1.0.0 集成 LLM-as-Judge 自动验证 |
