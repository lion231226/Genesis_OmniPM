# 瑜伽馆数字AI化运营系统 — Slice2 积分引擎 PRD

> **版本**：v1.0 | **父项目**：Slice1 约课核心闭环（已完成）

## 1. 产品愿景

**一句话**：让会员每一次消费/签到/推荐都能"看得见回报"——积分自动累积、灵活兑换、等级成长可视化。

**核心价值主张**：
- 🎯 **自动获取**：约课/签到/消费自动触发积分奖励，无需人工操作
- 💰 **灵活兑换**：积分可兑换课程券、商品券、余额抵扣
- 👑 **等级成长**：累积积分自动升级会员等级，解锁更多权益
- 📊 **透明可见**：每笔积分流水清晰可查，过期提醒

## 2. 用户角色与场景

| 角色 | 核心场景 | 频率 | 优先级 |
|------|----------|------|--------|
| 会员 | 查看积分余额和历史 | 每周 | P0 |
| 会员 | 积分兑换课程券/优惠券 | 每月 | P0 |
| 会员 | 查看会员等级和权益 | 按需 | P1 |
| 系统 | 约课完成后自动发放积分 | 每笔 | P0 |
| 系统 | 签到后自动发放积分 | 每天 | P0 |
| 运营 | 配置积分规则和兑换商品 | 按需 | P1 |

## 3. 功能边界

### 包含（In Scope）

#### 后端（5个功能模块）

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| B1 | **积分规则引擎** | 可配置的获取规则（消费/签到/推荐/新会员奖励），每种规则定义积分比率和上限 | P0 |
| B2 | **自动触发集成** | 在现有约课/签到/注册流程中嵌入 AwardPoints 调用 | P0 |
| B3 | **兑换商城** | 预定义兑换商品列表（课程券/优惠券/实物券），支持类型筛选和库存管理 | P0 |
| B4 | **积分过期** | 12个月滚动过期，定时任务标记过期积分 | P1 |
| B5 | **会员等级** | 基于累计积分的3级会员（银卡/金卡/钻石），自动升级+权益差异化 | P1 |

#### 小程序前端（2个页面）

| ID | 功能 | 说明 | 优先级 |
|----|------|------|--------|
| F1 | **积分中心** | 积分余额卡片 + 获取规则说明 + 最近流水列表 | P0 |
| F2 | **兑换商城** | 商品列表（分类筛选）+ 兑换确认弹窗 + 兑换记录 | P0 |

### 不包含（Out of Scope）

- 管理后台积分配置界面（本期通过数据库/配置文件管理）
- 推荐奖励链路追踪
- 积分赠送/转赠
- 积分营销活动（限时翻倍等）

### 现有资产（可复用）

- ✅ `PointRecord` / `CouponInstance` / `MemberTierLog` 3表模型
- ✅ `RedeemPoints()` — FIFO扣减+风控+幂等
- ✅ `AwardPoints()` — 积分发放+幂等
- ✅ `GET /points` / `GET /points/history` / `POST /points/redeem` 端点
- ✅ `PointsRepo` — 数据访问层

## 4. 数据新增

| 表 | 字段数 | 说明 |
|----|--------|------|
| `point_rules` | 8 | 积分获取规则配置（类型/比率/上限/启用状态） |
| `exchange_items` | 10 | 兑换商品定义（名称/类型/积分价格/库存） |
| `exchange_records` | 8 | 兑换记录（关联CouponInstance） |

## 5. 非功能需求

| 维度 | 要求 |
|------|------|
| 数据一致性 | 积分发放/扣减全部事务保护，幂等键去重 |
| 性能 | 积分查询 <100ms（member_id索引） |
| 过期处理 | 定时任务每天凌晨执行，单次处理≤1000条 |
| 安全 | 积分操作需JWT认证，兑换需二次确认 |
