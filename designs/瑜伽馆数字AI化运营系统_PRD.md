## 一、产品概述

### 1.1 一句话定位

**面向瑜伽/普拉提场馆的 AI 运营合伙人** — 不是工具，是替老板干活的数字员工。

### 1.2 核心价值主张

| 传统方式 | 本产品 |
|---------|--------|
| 老板手动排课、手动发消息、手动做报表 | AI 自动排课建议 + 自动触达 + 自动生成日报 |
| 会员来了就练、走了就忘 | 积分梯度锁客 + 里程碑激励 + 流失预警 |
| 新人靠前台口头跟进 | 8 步 SOP 全自动执行，7 天完成留存转化 |
| 数据在 Excel 里，决策靠感觉 | 实时经营看板 + 异常预警 + 成本风控 |
| 单店一套账，连锁管不了 | 多门店统一管控 + 跨店数据 + 总部台账 |

### 1.4 项目背景

本项目对标"瑜小九"（中国市场瑜伽 SaaS，服务 6 万+场馆），定位为**全面超越**的新一代 AI 驱动瑜伽运营系统。核心差异化在三个维度：

1. **AI 自动化运营**：系统主动分析 → 自动执行 → 老板只看日报
2. **积分梯度锁客**：四级会员等级 + 6 类自动积分奖励 + 5%-8% 安全成本区间
3. **新人留存 SOP**：全自动 8 步留存流程，从注册到第 8 次课，无人干预

### 2.2 竞争策略

- **不是做"更好的瑜小九"**：瑜小九已解决"能用"，我们解决"好用到离不开"
- **核心壁垒**：AI 运营引擎 + 积分梯度锁客体系（竞品短期无法复制）
- **切入点**：单店免费入门 → 标准版转化 → 连锁版扩张

### 6.2 核心交互流程

```
约课流程：
  打开课表 → 选择日期 → 点击课程 → 确认预约
    → 满员？ → 加入排队 → 有人取消 → 微信通知排上 → 确认/取消

签到流程：
  课程开始 → 会员到场 → 扫码签到/教练手动签到
    → 准时 → 计入有效课时 + 自动积分
    → 迟到/旷课 → 不计入

积分流程：
  完成课程（有效签到） → 系统自动判断 → 发放积分
    → 触发周满勤判断 → 触发30天满勤判断 → 触发梯度奖励
    → 积分到账微信通知 → 积分可抵扣/兑换
```

|------|------|------|---------|

- 连锁版：2,000家品牌 × ¥999 × 12 = ¥2,398万 ARR
- **潜在 ARR：~1 亿人民币**

### 9.3 多门店隔离策略

```
方案：共享数据库 + tenant_id 隔离
- 每张业务表包含 tenant_id 字段
- API 中间件从 JWT 提取 tenant_id → Gorm Scope 自动过滤
- 总部角色 tenant_id = NULL → 跨店查询权限
- 优点：单实例支持多门店，运维成本低；数据隔离在应用层保证
```

## 十、需求优先级与路线图

### 10.1 开发策略："垂直切片"

不按模块横向开发，而是按**用户可感知的完整功能切片**交付：

```
Slice 1: 约课核心闭环（已有基座，增强排队+签到）
  → 会员能约课/排队/签到 → 前台能操作 → 老板可看到出勤

Slice 2: 积分引擎上线
  → 出勤自动积分 → 积分可查 → 4级会员等级生效

Slice 3: AI触达基础版
  → 上课提醒 + 邀约 + 老板日报 → 系统开始"自己跑"

Slice 4: Web管理后台完整版
  → 全部管理功能可用 → 店长不再需要Excel

Slice 5: 新人SOP + 转介绍
  → 增长引擎上线 → 撕开与竞品的差距

Slice 6: 多门店 + 兑换商城 + 报表
  → 连锁版可用 → 可商业化销售
```
