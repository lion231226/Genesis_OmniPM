## 二、v2.0.0 vs v1.0.0-PI 核心差异

| 维度 | v1.0.0-PI | v2.0.0 |
|------|-----------|--------|
| 工作流 | 固定 5 步管道 (A→B→C→D→E) | 动态 DAG (3-15 节点，按需生成) |
| 专家评审 | 固定 8 人排队发言 | 按需激活 0-13 人，5 种强度 |
| 项目路由 | 关键词匹配 → 5 选 1 模板 | 深度分析（5 维度） |
| 设计覆盖 | 7 维度全覆盖 | 风险加权，不相关跳过 |
| 错误处理 | 固定 12 条回退路径 | 根因分析 + 动态回退 |
| 质量门控 | 固定 3 个 GATE | 1-5 个 GATE，风险自适应 |
| 修正机制 | 无 | 闭环修正 + 熔断（3次） |
| 跨会话恢复 | 手动检测 | DAG 节点级检查点 |
